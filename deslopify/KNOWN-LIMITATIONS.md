# Known limitations

## Release status

v1.0.0-rc.2 is undergoing fresh independent behavioral evaluation and operator scoring. A tooling pass alone is not a stable-release verdict.

The earlier retained RC.1 blind report removed the unsupported population attribution but preserved the redundant closing maxim: 1/4 missed removals (25%, fail). It also deleted the writer's separate admission and expressive "honestly". The prior completion message understated these failures. RC.2 narrows the attribution edit to preserve supported admissions, sharpens the redundant-closer test, and prevents voice samples from supplying unsupported new facts. The original oracle is unchanged.

## Measurement limits

Predicted writer reversions are model judgments, not observed author acceptance. A small fixed corpus measures specific regressions; it does not establish reliability across every subject, model, language, or audience. Self-checking is fallible. Review factual claims and consequential copy before publication.

## Supported scope

The corpus covers English nonfiction Edit, Draft, and Detect modes, including technical terms, personal voice, marketing with insufficient facts, and conflicting length targets. Multilingual editing, regulated-domain accuracy, and broad longitudinal production performance are not established by these tests. Detect reports prose patterns, never AI authorship.

## Packaging and trust

The install archive is intentionally minimal; development documentation and evaluation data remain in source. Verify with the builder from the matching source version. The manifest checks integrity and declared membership, not publisher identity. Builders require Python 3.11+ and pinned PyYAML; the installed skill has no execution dependencies.
